Professional PDF report update

1. Copy trained rockfall_v4_k9.joblib into this folder.
2. Activate your existing Python virtual environment.
3. Run: python -m pip install -r requirements.txt
4. Run: python app.py
5. Open http://127.0.0.1:5000
6. Assess a slope, then use Download PDF Report in the result panel.
7. Save multiple assessments and visit Assessment History to download a combined PDF report.

PDF reports are generated by Flask using ReportLab. Existing inference and trained model are unchanged. PDF reports show model-generated hazard scores, not event probabilities.
