PROFESSIONAL ASSESSMENT REPORTS

Replace index.html, app.js and style.css in your existing k=9 website, and ADD report.js.
Keep your trained rockfall_v4_k9.joblib in the same folder as app.py.
Start: python app.py
Visit: http://127.0.0.1:5000/#history
Save assessments first, then use Download Report (HTML) or Save as PDF.
For PDF, click Save as PDF, then Print / Save as PDF in the new tab and choose Save as PDF in the browser print dialog.
Individual assessment reports are available per history row.
Reports use only actual saved browser history. No sample values are fabricated.
No external JavaScript dependencies; report HTML works offline.
