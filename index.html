MODEL EVIDENCE

v4 · k=9 model insights

Gradient Boosting + Ridge ensemble. Route-wise validation is described in the supplied research notebook; deployment predictions use a full-data refit.

What is predicted?

The model predicts a total CDOT hazard score. Rock-type/slope-type thresholds classify it as Low, Moderate or High.

Probability disclaimer

No validated k=9 probability calibrator was exported. A predicted High class is not a 100% chance of rockfall.

Required assessment

Slope and ditch geometry, environmental and traffic ratings, and nine selected geological scores for the chosen rock type.

FIELD GUIDE · HOW TO COMPLETE THE FORM

About Inputs

A clear, practical guide to slope measurements, inspection scores, and geological ratings used by the CDOT v4 k=9 model.

Start here: In Step 1, enter the site details. In Step 2, provide actual slope measurements. In Step 3, enter the CDOT inspector ratings. Select each score using the official inspection worksheet criteria; choosing a higher number without evidence does not produce a valid assessment.

1 · Site details

Rock type

Select the rock material present at the slope: Crystalline (igneous or metamorphic), Sedimentary (layered sedimentary rock), ya Block in matrix (rock blocks embedded in a matrix). Choose based on documented field geology.

Slope type

Cut = a slope excavated during road construction; Total = the complete slope assessment category defined by the worksheet. Verify the slope type using the site record.

Engineering region

This is the CDOT engineering region code, not a postal code or an arbitrary number. Use the region recorded in the original CDOT site data.

CDOT rater (optional)

Identifier of the person who performed the inspection. If it is unavailable in the original record, leave it unspecified. Do not invent a rater ID.

2 · Slope & ditch measurements

Use the correct units: feet (ft) and degrees (°). These are measured values, not inspection rating scores.

Slope height · ft

The vertical height of the slope near the road. Enter the height in feet using a ground survey or verified field record.

Slope angle · °

The angle of the slope relative to horizontal ground. An angle of 0° is nearly flat and 90° is vertical. Use a clinometer or survey measurement.

Slope length · ft

The length of the slope segment defined by the worksheet. This is different from slope height; use the recorded measurement.

Ditch slope · °

The inclination angle of the roadside catch ditch. Do not confuse it with the main slope angle.

Ditch width · ft

The width of the roadside ditch intended to catch falling rock debris.

Ditch depth · ft

The vertical depth of the ditch. Enter zero only when the verified record indicates zero depth.

Traffic measurements

For numeric fields such as sight distance, accidents, speed and traffic volume, use verified site records and the units required by the original worksheet. Do not convert units without confirming the expected units.

3 · Environmental, traffic & slope ratings

These are worksheet-based assessment scores. Plain-language descriptions of each parameter appear below.

4 · Rock-specific geological scores

Geological items can differ for Crystalline, Sedimentary and Block in matrix rock types. After you select a rock type, the form displays nine applicable items. Their original worksheet labels appear below.

5 · Score selection: 0, 3, 9, 27, 81, 243

These are CDOT assessment codes, not percentages representing the chance of a rockfall. Each item may have a different scoring table. Therefore, it is incorrect to label 3 universally as “Low” or 81 universally as “High.” Match the observed condition to the official worksheet before entering a score.

Example (illustrative, not an official score rule): if an inspector has recorded rainfall conditions, consult the precipitation scoring criteria first and then select the corresponding score. Do not select 81 without supporting evidence.

The model uses thresholds on its predicted total score to assign a Low / Moderate / High category. This is not a probability of a future rockfall event.

ABOUT THE PROJECT

Highway Rockfall Hazard Classification

CDOT hazard classification using the v4 k=9 Gradient Boosting and Ridge ensemble.

Model implementation

The updated v4 k=9 model combines Gradient Boosting and Ridge regression to estimate a CDOT hazard score. Rock-type and slope-type thresholds convert the score into Low, Moderate or High inspection categories. This is not a real-time rockfall forecast.

Project developer

Navneet Gupta

Model methodology

The assessment uses slope geometry, environmental and traffic ratings, and nine selected geological scores for the applicable rock type. The model is evaluated with route-wise validation in the research notebook.

Prediction is served by a Flask backend using the exported k=9 ensemble. The notebook does not establish calibrated k=9 event probabilities.
